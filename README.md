# 🎬 Movie Analytics & Sentiment Engine

A simple multi-modal data dashboard built with Python and Streamlit that predicts movie watch metrics and analyzes customer feedback sentiment.

## ✨ Features
* **Movie Watch Predictor:** Uses **Linear Regression** to forecast how many total movies a customer will watch based on their membership months.
* **Feedback Sentiment Analyzer:** Uses **NLP (CountVectorizer)** and **Naive Bayes** to instantly classify customer text logs as positive or negative.

## 🛠️ Tech Stack
* Python
* Streamlit (Frontend Interface)
* Pandas (Data Handling)
* Scikit-Learn (Machine Learning & NLP)
